# Teste manual obrigatório — Gerar Relatório

## Quando usar
Usar este checklist sempre que houver mudança em:
- relatório
- PDF
- descrição de zona
- blocos adicionais do relatório
- ordem dos itens do relatório
- core/report_pdf.py
- ui/relatorio.py

## Checklist
- [ ] Gerar relatório com um caso válido
- [ ] Confirmar que a seção de descrição da zona aparece quando aplicável
- [ ] Confirmar que a descrição da zona aparece apenas uma vez
- [ ] Confirmar que a descrição da zona está na posição correta do relatório
- [ ] Confirmar que os demais blocos do relatório continuam aparecendo
- [ ] Confirmar que nenhuma informação anterior sumiu
- [ ] Confirmar que o botão/ação de gerar relatório continua funcionando
- [ ] Gerar o PDF
- [ ] Confirmar que o PDF abre corretamente
- [ ] Confirmar que o PDF baixa corretamente
- [ ] Confirmar que o PDF não quebrou visualmente
- [ ] Confirmar que textos, figuras e blocos não ficaram sobrepostos
