# Teste manual obrigatório — Login / Sessão

## Quando usar
Usar este checklist sempre que houver mudança em:
- login
- sessão
- topo
- Área do cliente
- app.py
- auth

## Checklist
- [ ] Clicar em “Entrar com Google”
- [ ] Concluir login com sucesso
- [ ] Voltar para o sistema já autenticado
- [ ] Confirmar que o nome/e-mail do usuário aparecem
- [ ] Atualizar a página e confirmar que continua logado
- [ ] Abrir a Área do cliente pelo topo
- [ ] Confirmar que a Área do cliente abre sem perder a sessão
- [ ] Fazer logout
- [ ] Confirmar que saiu da conta corretamente
- [ ] Fazer login com outra conta
- [ ] Confirmar que a troca de conta funcionou
