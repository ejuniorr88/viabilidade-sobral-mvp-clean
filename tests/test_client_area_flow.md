# Teste manual obrigatório — Área do cliente

## Quando usar
Usar este checklist sempre que houver mudança em:
- Área do cliente
- topo
- login
- sessão
- auth
- app.py
- listagem de relatórios
- client_reports

## Checklist
- [ ] Clicar em “Área do cliente” no topo
- [ ] Confirmar que a área abre sem perder a sessão
- [ ] Se estiver deslogado, fazer login
- [ ] Confirmar que o retorno do login vai para a Área do cliente
- [ ] Confirmar que o nome do usuário aparece
- [ ] Confirmar que o e-mail do usuário aparece
- [ ] Confirmar que o saldo de créditos aparece
- [ ] Confirmar que os relatórios salvos aparecem na lista
- [ ] Confirmar que a data e a hora dos relatórios aparecem corretamente
- [ ] Confirmar que o download do relatório funciona
- [ ] Atualizar a página e confirmar que a sessão foi mantida
- [ ] Fazer logout e confirmar que saiu corretamente
