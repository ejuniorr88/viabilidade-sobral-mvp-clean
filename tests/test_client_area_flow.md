Checklist manual — Área do cliente (função blindada)
Fluxo obrigatório
Clicar em Área do cliente no menu superior.
Confirmar abertura sem perder a sessão.
Se estiver deslogado, fazer login com Google.
Confirmar retorno automático para Área do cliente.
Validar que `auth_logged_in`, `auth_user_id` e `auth_user_email` permanecem válidos.
Confirmar ausência de regressão visual no topo.
Regressões proibidas
Não usar link HTML/query string que recarregue a página e perca a sessão.
Não exigir novo login quando a sessão já estiver ativa.
Não abrir a página errada após o login.
