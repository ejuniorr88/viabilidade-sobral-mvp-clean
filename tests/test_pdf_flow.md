# Teste manual obrigatório — PDF

## Quando usar
Usar este checklist sempre que houver mudança em:
- core/report_pdf.py
- ui/relatorio.py
- descrição da zona no relatório
- blocos do relatório
- figuras do relatório
- geração/download do PDF

## Checklist
- [ ] Gerar um relatório válido
- [ ] Clicar para gerar/baixar o PDF
- [ ] Confirmar que o PDF é gerado sem erro
- [ ] Confirmar que o PDF abre corretamente
- [ ] Confirmar que o download funciona
- [ ] Confirmar que o texto não ficou sobreposto
- [ ] Confirmar que os títulos e blocos aparecem na ordem correta
- [ ] Confirmar que a descrição da zona aparece quando aplicável
- [ ] Confirmar que a descrição da zona aparece só uma vez
- [ ] Confirmar que as figuras/imagens aparecem quando aplicável
- [ ] Confirmar que o PDF não ficou cortado ou quebrado visualmente
